# Cover Letter Generation Prompt

Use this prompt when asked to write a cover letter for a job lead.

---

Read `resume.md` and `job_search_profile.md`. Then write a tailored cover letter for the following role:

**Company:** [COMPANY]
**Role:** [ROLE TITLE]
**Job Description:**
[PASTE JOB DESCRIPTION HERE]

Guidelines:
- 3–4 short paragraphs, under 350 words
- Opening: connect a specific achievement from my resume to a clear need in this role
- Middle: highlight 2–3 relevant accomplishments with concrete metrics where possible
- Closing: express genuine interest in the company and a call to action
- Tone: confident, direct, not generic — avoid "I am excited to apply"
- Do not repeat the resume verbatim; synthesize and reframe for this specific role

Output the cover letter as plain text, then save it as `cover_letters/[company]-[role].md`.
