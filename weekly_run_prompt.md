# Weekly Run Prompt

Copy and paste the block below at the start of each Monday session.

---

It's my weekly job hunt session. Go through this in order:

1. **Profile check** — Open `job_search_profile.md` and read it back to me in full (target
   roles, locations, industries, comp floor, work arrangement, search urgency, hard
   constraints). Ask if anything needs updating before we proceed. Wait for my confirmation
   before moving on.

2. **Run the workflow** — Follow every step in `weekly_job_hunt_workflow.md`, in order, start to
   finish. For any step that needs my input (resume/profile mismatch, which leads I actually
   submitted, follow-up drafts), pause and ask before continuing rather than guessing.

3. **New leads added** — Once the workflow's scrape and filter steps are done, show me every
   row that got added to `job_leads.md` this run, so I can see what's new before we go further.

4. **Draft one outreach email** — From everything currently in `job_leads.md`, identify the
   single strongest lead: clears the comp floor (by the widest margin if Search Urgency in
   `job_search_profile.md` is Passive, otherwise just needs to meet it), strongest company, best
   role match. Draft one short outreach email under 200 words in my voice: direct, no em dashes,
   clear ask for a 20-minute call. Base it on `resume.md` and `job_search_profile.md` — don't
   invent experience I don't have. Show me the draft and wait for my go-ahead before saving it
   anywhere.

When everything above is done, print the weekly summary from the last step of
`weekly_job_hunt_workflow.md`.
